# SRT项目：基于自组织临界状态的类脑信息处理过程研究

贵州大学"SRT计划"项目资助（项目编号：2025SRT254）

本项目为大学生创新训练计划（SRT）的配套代码库，研究自组织临界态（SOC）
在类脑信息处理中的动力学作用。论文对应《基于自组织临界状态的类脑信息处理
过程研究——SRT项目研究报告》。

## 内容结构

| 目录 | 内容 | 对应论文 |
|------|------|----------|
| sandpile/ | BTW沙堆模型异步仿真、熵分析、幂律拟合、扰动系综实验 | 3.1节、4.1节、表1、图1、图2 |
| snn_training/ | 10层/15层残差SNN的MNIST训练脚本（4组β） | 3.2节、表2、表4 |
| avalanche_analysis/ | 雪崩识别、分支参数σ、幂律指数τ拟合 | 3.3节、表3、图4 |
| mlp_prediction/ | 无记忆/带记忆MLP时间序列预测 | 3.5节、4.3节、图5 |
| data/logs/ | 训练日志 | 表2、表4的原始依据 |

## 环境

Python 3.x；torch、snntorch、scipy、matplotlib（版本见 requirements.txt）

## 复现步骤

1. 沙堆仿真：`python sandpile/sandpile_simulation_entropy.py`（seed=42，Zc=4，10000步）
2. 熵变曲线：见 sandpile 目录对应脚本
3. SNN训练：见 snn_training 目录各配置脚本（β=0.90/0.95/0.97/0.99 × 10/15层）
4. 雪崩统计：avalanche_analysis 目录探针脚本逐层记录脉冲，按式(2)计算σ
